# UpgradeGuard

UpgradeGuard is an autonomous dependency upgrade investigator for Node.js/npm repositories. It determines whether a dependency upgrade can safely be applied to a specific repository — researching the upgrade, testing it inside an isolated sandbox, running the repository's own tests and build, and producing a structured Upgrade Report — before any change is made to the real repository.

Built for the 2026 Agent Harness Hackathon.
